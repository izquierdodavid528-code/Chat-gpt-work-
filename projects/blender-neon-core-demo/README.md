# Blender Neon Core Demo

A short 5-second vertical 3D proof-of-quality built entirely in Blender.

## Visual concept

A luminous energy core suspended inside a rotating metallic cage:
- reflective platform and floor;
- emissive cyan core;
- animated orbital rings;
- wireframe geometry;
- orbiting particles;
- dramatic camera move;
- depth of field;
- compositor glow.

The scene is intentionally compact enough to render on a CPU-only GitHub runner while still demonstrating the look we can build for future projects.

## Output

- 720x1280
- 24 fps
- 120 frames / 5 seconds
- EEVEE
