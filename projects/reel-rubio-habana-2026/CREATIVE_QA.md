# CREATIVE QA — Reel Rubio / La Habana 2026

This gate is mandatory before the 60-second master render.

Technical PASS does not imply creative PASS.

## Gate A — Thesis
- [ ] In the first 5 seconds, a viewer can state the core idea in one sentence.
- [ ] The reel does not reduce the story to “Rubio vs Cuba”.
- [ ] It is clear that presidential orders, State and Treasury/OFAC are distinct actors.

## Gate B — Narrative continuity
- [ ] Every scene answers “what changed next?”
- [ ] Time jumps are explicitly motivated by dates or visual transitions.
- [ ] No chapter begins with a hard semantic jump from the previous one.
- [ ] The February rollback of the IEEPA tariffs is visible; January is not presented as a measure that simply persisted unchanged.

## Gate C — Visual quality
- [ ] 9:16 is intentionally composed; no persistent dead vertical space.
- [ ] No single layout is reused for most of the reel.
- [ ] Blender assets are used only when they outperform a simpler Remotion solution.
- [ ] Maps, documents and objects look materially plausible.
- [ ] Real political figures use authentic still/video material, not synthetic documentary-looking footage.
- [ ] Effects explain transitions or mechanisms; they are not decoration.

## Gate D — Audio
- [ ] Music is perceptible from the hook and supports the full arc.
- [ ] Music never masks narration.
- [ ] SFX mark only meaningful events.
- [ ] Room tone / transitions do not expose awkward edits.
- [ ] Final master target ~-15 LUFS, true peak <= -1.5 dBFS before QA.

## Gate E — Captions
- [ ] Captions are aligned to the final narration waveform/transcript, not estimated timestamps.
- [ ] No subtitle visibly lags the spoken phrase.
- [ ] Lines are short enough to read on mobile.
- [ ] Captions do not compete with maps/data labels.

## Gate F — Factual integrity
- [ ] Each factual scene has a source ID in RESEARCH_BRIEF.md.
- [ ] Rubio is not credited with orders signed by Trump.
- [ ] Claims by Washington or Havana are clearly attributed.
- [ ] No animation is presented as evidence of an event that was not filmed.
- [ ] No disputed causal claim is presented as settled fact.

## Stop conditions

Do NOT proceed to the 60-second production master if any of these fail:
- thesis clarity;
- chronology;
- caption sync;
- 9:16 composition;
- factual attribution;
- music/narration balance.

The correct response to a failed gate is redesign, not additional rendering.
