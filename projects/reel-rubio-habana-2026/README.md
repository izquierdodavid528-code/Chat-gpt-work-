# Reel Rubio / La Habana 2026

Estado: estrategia + investigación.

Tesis:
**En 2026 la presión de Washington sobre La Habana se amplió por capas: energía, sanciones, finanzas y movilidad.**

Este proyecto es strategy-first. No pasar al render completo hasta que:
1. fuentes factuales estén bloqueadas;
2. narración esté verificada;
3. storyboard/animatic de 15–20 s pase Creative QA;
4. lenguaje visual esté probado;
5. música y subtítulos estén sincronizados.

Archivos de verdad:
- CREATIVE_MASTER_PROMPT.md
- RESEARCH_BRIEF.md
- edit-plan.json
- project.config.json

Remotion será el master final.
Blender sólo se usará donde el 3D mejore comprensión.
