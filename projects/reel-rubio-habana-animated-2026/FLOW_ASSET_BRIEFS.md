## Shared art-direction rules

- Original hand-drawn 2D/cut-paper editorial cartoon, warm textured paper, dark ink outlines, layered foreground/midground/background, restrained navy/sea-blue/coral/mustard/olive palette.
- Use the supplied character master and style still as identity/style anchors. Match face, hair, age, suit, red tie, body proportions, outline and palette across shots.
- One readable action and one intentional camera move per generated shot. Create a clear end pose or object position that Remotion can use for a match cut.
- No photorealism, fabricated documentary footage, extra politicians, logos, watermarks, UI, legible generated text, dates, labels or accurate maps. Add verified facts, geography and typography later in Remotion.
- Keep clips separate, preferably 4–6 seconds. Use 6 seconds for the planned tests. Trim the useful action in Remotion; do not stretch weak motion.
- Generate one candidate per prompt first. Review it at normal phone size. If it fails, change only the failing variable (pose, face stability, action, or camera) and re-run.
