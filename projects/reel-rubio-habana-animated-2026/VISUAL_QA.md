# VISUAL QA GATE — Illustrated Explainer

The project fails creative QA if any of these are violated.

## 1. No slide language

Fail examples:
- static headline + paragraph + icon card;
- dashboard grids;
- information boxes that replace animation;
- scenes that could be exported as a carousel without losing meaning.

Pass:
- the event is represented by an object or character doing something.

## 2. Action density

Target:
- meaningful visual event every 0.7–1.5 seconds;
- no major object should remain completely static for more than ~2 seconds unless camera or secondary motion continues.

## 3. Text discipline

- text supports the drawing; it never becomes the scene;
- prefer dates, names, single labels and short attributed phrases;
- narration carries explanatory sentences;
- remove explanatory on-screen paragraphs whenever the action already communicates the point.

## 4. Physical transitions

Preferred:
- match cut;
- object transforms;
- paper wipe;
- zoom into/out of an object;
- one prop becomes the next scene.

Avoid:
- generic fade to a new slide;
- horizontal carousel transitions;
- full-screen title cards between chapters.

## 5. Secondary motion

After objects land:
- small bob;
- spring settle;
- slight hand-drawn rotation;
- route motion;
- camera drift.

Nothing should feel pinned to a PowerPoint canvas.

## 6. Political figures

- clearly illustrated or authentic sourced media;
- never synthetic documentary-looking footage;
- role labeling must match documented office/action;
- do not visually imply Rubio signed presidential executive orders.

## 7. Factual animation

Every metaphor must preserve scope:
- January tariff route visibly changes in February;
- finance scene does not imply all Cuba transactions are blocked;
- mobility scene does not imply a blanket travel ban;
- competing official framings are visually attributed.

## 8. Full-run review points

Audit at minimum:
- 00:02
- 00:06
- 00:11
- 00:16
- 00:21
- 00:27
- 00:32
- 00:38
- 00:44
- 00:50
- 00:55
- 00:59

Any collision, dead zone, or slide-like frame blocks final narration production.
