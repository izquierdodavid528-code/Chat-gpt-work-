# Rubio Habana 2026 — Hook Map

5-second Blender asset for the opening of the Rubio/Havana 2026 reel.

Purpose:
- establish geography immediately;
- make the layered-policy thesis visual;
- prove the project can achieve a cinematic 3D language before building the rest.

Visual policy:
- Cuba/Florida recognizable;
- stylized but geographically grounded;
- no fabricated political footage;
- no military spectacle;
- rings represent policy layers, not literal physical actions.

This scene is keyframe-only and contains no sequential simulation. Parallel rendering is safe.
