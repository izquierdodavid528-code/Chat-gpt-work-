# WOW Workspace Demo

A short vertical motion-design test built to validate the automated creative workspace.

## Concept
A 12.4 second technology ident that moves through:

1. IDEA
2. CODE → MOTION
3. BUILD / PREVIEW / RENDER
4. SYSTEM ONLINE

No external media is required. The visual language is generated entirely with Remotion: particles, orbital geometry, perspective grid, glass panels, kinetic typography and frame-driven transitions.

## Run in Codespaces

```bash
npm run studio -- wow-workspace-demo
```

## Final render

Use the **Remotion Drive Render** workflow with:

- project_slug: `wow-workspace-demo`
- repo_project_dir: blank
- drive_project_dir: blank

The project metadata resolves Drive automatically to:

`Remotion Projects/02 - WOW Workspace Demo`

Output: `wow-workspace-demo.mp4`
