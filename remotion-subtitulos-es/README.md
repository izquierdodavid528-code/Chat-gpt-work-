# Remotion – subtítulos en español

Proyecto autocontenido para el clip `1002974408.mp4`.

## Especificaciones
- Resolución: 640×360
- FPS: 60
- Duración del master: 127.658667 s
- Composición Remotion: 7660 frames (~127.67 s)
- Subtítulos: español, máximo 2 líneas, zona segura inferior
- Video base: `public/input.mp4`

## Ejecutar

```bash
npm install
npm run start
```

## Renderizar

```bash
npm run render
```

Salida esperada:

```
out/subtitulos-es.mp4
```

El archivo `subtitulos_es.ass` se incluye como referencia/editable adicional.
